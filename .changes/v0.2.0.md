* Headings in `fseo-section--dark` bands were dark on dark because the base heading color rule was more specific.
* Header and footer template-part selectors used `:first-of-type` / `:last-of-type`, so the `<header>` picked up footer styles and the footer became sticky; they now use `:first-child` / `:last-child`.
