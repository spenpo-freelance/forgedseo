# ForgedSEO Core

Custom plugin for forgedseo.com. Holds design tokens, CSS, JS, and the `[forgedseo_cta]` shortcode. Deployed by GitHub Actions rsync on push to `main` (production only).

Do not install this from WordPress.org. After rsync, activate in wp-admin (Plugins → ForgedSEO Core). Pair with the Twenty Twenty-Five theme.
